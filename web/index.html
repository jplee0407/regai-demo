GitHub 기능이 그대로 지식 갱신 절차가 됩니다. 아래 링크로 실제 동작을 확인할 수 있습니다.

직접 시연하기

  1. 저장소 Actions → 법령 개정 감시 → Run workflow → mode에서 simulate 선택 후 실행
  2. 몇십 초 뒤 Pull requests에 "[가상 개정]" 갱신안이 올라옴 (신·구 대조, 영향 분석, AI 규칙 초안, 판정 변화 미리보기 포함)
  3. PR 본문 맨 아래의 정답셋 회귀 테스트 결과 확인 → Review → Approve → Merge
  4. 몇 분 뒤 이 화면이 새 규칙으로 갱신됨. 기준일을 2027-01-15로 바꾸고 ① 변경 판정을 다시 하면 기한이 60일 전으로 계산됨
  5. 되돌리려면 병합된 PR의 Revert 버튼 → 이전 규칙으로 복구
